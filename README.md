# My Backend Project

A **Next.js** backend project powered by a **PostgreSQL** database.

## Features
- REST API endpoints for user management.
- PostgreSQL integration for data persistence.
- Deployment-ready with CI/CD using GitHub Actions and DigitalOcean.

## Installation

### 1. Clone the Repository
```bash
git clone https://github.com/narinderdev/glowante-backend.git
cd glowante-backend


This is a [Next.js](https://nextjs.org) project bootstrapped with [`glowante-backend`](https://nextjs.org/docs/app/api-reference/cli/glowante-backend).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
